A program that writes exactly one letter to `/output/entry.txt`, for the
make.fun competition
[One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

Run it with Python 3:

```
python3 main.py
```

It writes the letter below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The letter is 1 character, inside the 1 to 1 gate.

## The letter

```
W
```

W stands for whirlwind, the word for the day: a whirlwind of bounty
builds and ten minute checks from morning to late night, swept from one
entry to the next. Vivid and specific, funny because it is true, and W
suits the word, shaped like wind swirling, not the obvious pick.
